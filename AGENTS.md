# AGENTS.md

This repository is a local-first, static resume editor. Read this before changing code with an AI agent (Codex, Claude, DeepSeek, etc.).

## Product invariants

1. **Local-first.** No backend, accounts, telemetry, or uploads in the app. Data lives in `localStorage`.
2. **Never fabricate resume claims.** Only use facts present in the user's data or chat history. Never invent employers, dates, metrics, tools, or awards.
3. **Keep Chinese and English profiles independent.** Do not auto-translate or overwrite the other language unless explicitly asked.
4. **The preview is the visual source of truth.** PDF, PNG, and "Word（与预览一致）" are rendered from the preview DOM. The editable Word is approximate and must stay labeled as such.
5. **Downloads follow the selected resume.** While previewing a library card, `viewState()` is the selected resume; downloads use it. File names use `state.meta.title`.
6. **Photo changes sync to every library entry and both languages.**
7. **Preserve storage keys and schema.** Keys start with `resume-studio.v1`. Add migrations keyed with `resume-studio.v1.<migration>-<date>`; never silently wipe user data.
8. **Private data never enters the repo.** Keep personal resume JSON and research dumps in `private/` (gitignored). `src/demo/data.js` is demo data only.
9. **Visual exports are image-based.** This is intentional for visual fidelity; keep the editable Word option available.

## Change workflow

1. Read `docs/ARCHITECTURE.md` and the relevant section of `src/app.js`.
2. Make the smallest change that preserves the invariants above.
3. Run `npm run check` and `npm run lint`.
4. Run `npm run build`.
5. Run `npm test` (uses local Chrome; set `CHROME_PATH` if needed).
6. Manually verify: Chinese one page, library preview → 修改, title, download menu.
7. Update `CHANGELOG.md` and docs if behavior changes.

## Agent-written resume data

Agents should produce a **full v1 state JSON** (not a diff) and must run:

```bash
node scripts/agent.mjs apply <candidate.json>
```

The CLI validates the JSON, backs up the previous master, and writes `private/agent/resume-import.json`. The user imports that file in the app. Do not write directly into browser `localStorage`.

Use the prompt generated by `node scripts/agent.mjs prompt --history <chat.md>`; do not add facts that are not in the chat or current resume.
